# ЗАВДАННЯ: щоденний загальний дайджест NewsRadar (автоматичний запуск)

Ти працюєш **без людини**. Ніхто не відповість на питання – не питай, ухвалюй рішення сам, керуючись цією інструкцією. Мова дайджесту – українська. Усі шляхи нижче – від кореня репозиторію.

## Крок 0. Дата
Визнач сьогоднішню дату за Києвом: `TZ=Europe/Kyiv date +%F` (для назв файлів) і людський формат («27 жовтня 2026»).

## Крок 1. Методика
Прочитай `newsradar/instructions/instrukciya-v3.md` повністю – це головна методика (відбір за наслідковістю, сигнальна шкала, стиль, правила цитування). Застосовуй її **з такими змінами**, вони мають пріоритет:

1. **Режим Research вмикати не треба.** Для пошуку й докачування використовуй інструменти WebSearch і WebFetch.
2. **Агрегатор: спершу згенеруй свіжу стрічку сам.** У корені лежить `digest-feed.json`, але робот на GitHub оновлює його із затримкою – о 07:00 за Києвом він зазвичай ще вчорашній (≈10 годин, тобто без нічних новин США). Тому почни з власного прогону:
```
REPO="$PWD"; mkdir -p /tmp/nr-feed && cd /tmp/nr-feed && timeout 900 python3 "$REPO/aggregate.py"; cd "$REPO"
python3 - <<'PY'
import json
old = json.load(open("digest-feed.json"))
try:
    new = json.load(open("/tmp/nr-feed/digest-feed.json"))
except Exception as e:
    print("СВІЖА НЕ ВИЙШЛА:", e); raise SystemExit
print("у репозиторії:", old["total_items"], old["generated_at"])
print("свіжа:        ", new["total_items"], new["generated_at"])
print("БЕРИ СВІЖУ" if new["total_items"] >= 0.6 * old["total_items"] else "БЕРИ ЗБЕРЕЖЕНУ")
PY
```
`aggregate.py` працює на самій лише стандартній бібліотеці Python – встановлювати нічого не треба, триває 1–3 хвилини. Пише він у **поточну** папку, тому запуск із `/tmp/nr-feed` навмисно не чіпає файл у репозиторії: інакше `publish.sh` не зміг би зробити `git pull --rebase`.

**Яку стрічку брати.** Свіжу (`/tmp/nr-feed/digest-feed.json`) – якщо прогін удався і матеріалів у ній не менше 60 % від збереженої. Інакше збережену (`digest-feed.json` у корені), і познач це в `coverage`. Якщо й збережена старша за 30 годин – працюй у запасному режимі (тематичні запити), теж із позначкою в `coverage`.

**Як читати.** Файл великий – читай його **скриптом (python)**, а не цілком у контекст: виведи заголовки, джерела й дати, згрупуй за сюжетами.
3. **Попередні випуски** – у `newsradar/archive/main/`. Прочитай 3–5 найсвіжіших (за датою в назві файлу) для колонки «ТИЖДЕНЬ ТОМУ».
4. **Верстку не пиши сам.** Тобі потрібно лише заповнити JSON за зразком `newsradar/templates/main.example.json`. PDF, Telegram і архів зробить скрипт.
5. Word, docx-skill, LibreOffice вручну – **не потрібні**.

## Крок 2. Збір і відбір
Виконай розділи 3–4 методики: агрегат суцільно → піки за наслідковістю → активний пошук (під кожен пік + відкритий запит «сліпих зон» + чеклист тихих категорій) → відбір **15–21** публікації у **5–8** блоків → докачування фактів і **прямих URL**.

## Крок 3. Заповни JSON
Створи файл `newsradar/data/main-РРРР-ММ-ДД.json` (папку створи, якщо її немає). Структура – точно як у зразку. Правила:

- `type`: `"main"`; `date_iso`: `"РРРР-ММ-ДД"`; `date_label`: «27 жовтня 2026»; `issue`: `"ЩОДЕННИЙ ВИПУСК"`.
- `stats.materials` = `total_items` з агрегатора; `stats.sources` = кількість фідів, що дали матеріали; `selected` і `blocks` – фактична кількість. **Жодних вигаданих цифр.**
- `signals` – **рівно 5**; `sig` лише одне з: `КРИТИЧНО`, `УВАГА`, `СТАБІЛЬНО`.
- `summary`: `picture`, `theses` (2–4 абзаци), `ukraine` (`opportunities`, `risks`, `watch`), `notable`.
- `dynamics` – 4–5 рядків (Підтримка України; Мирні переговори; НАТО / безпека; Путін / Росія; База Трампа / США). Тема без попередньої згадки → `"before": "нова тема тижня"`.
- `blocks` – 5–8; у кожного `title`, `short` (2–3 слова для таблиці), `trend`, `articles`, `means` (1–3 речення про вплив на Україну).
- Кожна стаття: `title` (українською), `sig`, `paywall` (true/false), `media`, `date`, `meta` («Видання · жанр · ДД.ММ.РРРР»), `url` (прямий перевірений; немає надійного – `""`), `text` (переказ своїми словами, 120–250 слів), `quote` (`{"text","attr"}` або `null`), `also`.
- `comment` – 2–4 абзаци авторського коментаря.
- **Цитати** – до 15 слів, не більше однієї на джерело. Перекази – своїми словами.
- **Тире – лише середнє «–»**, ніколи «—». Без блоку «Застереження» і без «кухні» збору (агрегат, RSS, пейволи) у текстах.
- Файл має бути **валідним JSON** (перевір: `python3 -m json.tool файл > /dev/null`).

## Крок 4. Опублікуй
```
bash newsradar/scripts/publish.sh newsradar/data/main-РРРР-ММ-ДД.json
```
Скрипт зверстає PDF, надішле його в Telegram, збереже .md в `newsradar/archive/main/` і запушить у гілку `main`.

**Після рядка `TELEGRAM: надіслано` публікувати повторно ЗАБОРОНЕНО** – випуск уже в читачів. Якщо помітив недолік після відправки – не перевидавай, а згадай про це у фінальному звіті.

## Крок 5. Якщо щось пішло не так
- Скрипт написав `ПОМИЛКА` – прочитай причину, виправ JSON і запусти ще раз (максимум 2 повтори).
- Якщо не вдається – надішли повідомлення: `bash newsradar/scripts/notify.sh "❌ NewsRadar: <коротко що сталося>"` і заверши.

**Коли повторювати можна, а коли ні.** Повторний запуск `publish.sh` дозволений, лише якщо рядка `TELEGRAM: надіслано` у виводі **не було** – тобто випуск до читачів не дійшов. Якщо цей рядок був, а впало щось після нього (наприклад, збереження архіву в GitHub) – `publish.sh` **не перезапускай**: розберись із тим, що саме впало, і зазнач це у звіті.

## Заборонено
Не створюй pull request. Не змінюй інші файли, крім `newsradar/data/` (архів оновлює скрипт). **Не коміть `digest-feed.json`** – свіжу стрічку генеруй у `/tmp/nr-feed`, як описано в Кроці 1. Не змінюй `.github/` та `aggregate.py`.
